# Online Learning Cohort Analysis | Power BI

## Overview

This project analyzes student enrollment patterns, learner engagement, cohort retention, course participation, and revenue for a fictional online learning platform using Microsoft Power BI.

It demonstrates dimensional modeling, data transformation, DAX calculations, and interactive dashboard development to derive insights into student behavior and platform performance.

## Objectives

- Analyze student enrollment trends over time.
- Identify enrollment cohorts based on students' first enrollment month.
- Track monthly active learners and learning activity.
- Measure student retention across different cohorts.
- Compare course participation and revenue contribution.
- Develop an interactive dashboard for data-driven decision-making.

## Tech Stack

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures, calculated columns, and cohort calculations
- **Microsoft Excel** — Sample dataset
- **Dimensional Modeling** — Organizing data into dimension and fact tables

## Dataset

The project uses a fictional sample dataset created for educational and analytical purposes.

| Table | Description |
|---|---|
| Students | Student IDs, names, locations, and signup dates |
| Courses | Course IDs, course names, categories, and prices |
| Enrollments | Enrollment records, dates, and amounts paid |
| Learning Activity | Student activity dates, activity types, and learning duration |

## Data Model

The project follows a star-style dimensional modeling approach.

- **Dim_Student:** Student information and cohort attributes
- **Dim_Course:** Course details and categories
- **Dim_Date:** Calendar attributes for learning activity analysis
- **Dim_Enrollment_Date:** Calendar attributes for enrollment analysis
- **Fact_Enrollments:** Enrollment transactions and revenue
- **Fact_Learning_Activity:** Student learning events and time spent

The dimension tables connect to the corresponding fact tables through student, course, and date keys.

## Key Performance Indicators (KPIs)

- Total Revenue
- Total Enrollments
- Total Students
- Active Learners
- Total Learning Activities
- Total Learning Minutes
- Average Revenue per Enrollment
- Cohort Retention Percentage

## Dashboard Features

- **Enrollment Trends:** Analyze enrollment volume over time.
- **Active Learner Analysis:** Track students with recorded learning activity.
- **Course Participation:** Compare engagement across courses.
- **Revenue Analysis:** Evaluate revenue generated by enrollment cohorts.
- **Cohort Retention Matrix:** Visualize learner retention by cohort month and months since first enrollment.
- **Interactive Slicers:** Filter analysis by course category, state, cohort month, and enrollment month.

## Cohort Analysis Methodology

Students are assigned to cohorts based on the month of their first recorded enrollment.

The cohort month index represents the number of calendar months between the student's first enrollment month and a subsequent learning activity month.

Retention is calculated as:

**Retention (%) = (Active Learners in Month N / Active Learners in Month 0) × 100**

This helps evaluate how learner engagement changes over time.

Active learners are counted as distinct students with recorded learning activity during the selected period.

## How to Run the Project

1. Download the sample Excel workbook from the `data/` directory.
2. Open Power BI Desktop.
3. Select **Home → Get Data → Excel Workbook**.
4. Import the Students, Courses, Enrollments, and Learning Activity sheets.
5. Clean and transform the data using Power Query.
6. Create the dimensional model and relationships.
7. Implement the required DAX measures and cohort calculations.
8. Build the dashboard and explore the interactive visualizations.

If the completed `.pbix` file is available, open it directly in Power BI Desktop to explore the report.
